# F4 — UI/UX Pro Max aplicado desde la fuente canónica

Origen: `vendor/v8/vendor/locked-skills/ui-ux-pro-max`; el sincronizador oficial no pudo reemplazar la carpeta global bloqueada. Se leyó y ejecutó la copia canónica, con SHA registrado. No se usa la guía global antigua, orientada a React Native, como contrato de esta web Next.js.

Operación real: búsqueda Python «focus not obscured fixed consent banner» en dominio ux. Devuelve Focus Not Obscured mínimo AA y ampliado AAA por separado, más navegación fija. Aplicación: altura del aviso medida por ResizeObserver; scroll-padding y espacio de documento coherentes; foco ajustado y menú desplazable en landscape; controles de consentimiento >=44px. No se llama AAA un requisito AA.

Entrada: copy/CRO, tokens actuales, componentes de navegación, consentimiento, hero y CTA. Hallazgos: hero móvil demasiado alto, controles bajo overlay, menú sin fallback JS, preferencias ausentes en legales y ampliación de texto que podía ensanchar la página. Corrección y retest en pruebas de navegador; se conservan fuentes y colores de marca.

El índice ya cumple una función de elección de servicio y mensaje contextual. No se agrega un panel falso. 21st se investigó y se descartó con límites explícitos. Archivos: globals.css, Nav, TrackingConsent, LegalPage, HeroTitle y tests. Limitación de instalación global conservada como BLOCKED, no disimulada por la operación sobre código.
